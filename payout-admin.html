Admin tools for browser popups and the optional SL Pay shortcut.

Quick check

If nothing pops up

Chromium/Chrome: click the site-controls icon next to the address bar → Site settings → Notifications → Allow, then reload.

Windows: the alert normally appears as a lower-right toast and is also available in Notification Center. Check Windows Settings → System → Notifications if needed.

Linux: the alert appears through the desktop notification system (KDE/GNOME/etc.). Check your desktop notification settings for Chromium if the local test is silent.
