💬 In-world Payout Reminder

A tiny SL object that reminds you when a 1,000 L$ payment is due.

No automatic money transfer

This version does exactly one job: it checks the Passport Adventures reward balance and sends the object's owner an IM when at least 1,000 L$ is ready to pay.

Safe and simple: no pairing code, no avatar UUIDs, no debit permission, and no L$ transfer function. You pay your benefactor manually in Second Life, then press Mark 1,000 L$ paid on the website.

1. Make the reminder object

1
Rez any small prim that you own. Name it something like Passport Pay Reminder.
2
Open the prim's Contents, create a new script, replace the default script with the reminder script below, and save.
3
That's it. The object checks once per minute and IMs its owner only when a 1,000 L$ payment is available. Touch it any time to force an immediate check.

2. Test it without completing an adventure

On the Adventures page, press 🧪 Pretend [recipient] has earned 1,000 L$.

The website temporarily exposes a 1,000 L$ test balance to the reminder object. Within about a minute, you should receive an in-world IM telling you that a payment is due.

Nothing is paid, no adventure is completed, and no real reward balance changes. When you're done, press Clear 1,000 L$ test earnings.

3. Normal use

Adventure rewards accumulate normally. Once the unpaid balance reaches 1,000 L$, the reminder object IMs you. If the balance supports more than one 1,000 L$ payment, the message tells you how many are available.

After you manually pay 1,000 L$ to the recipient in Second Life, return to the Adventures page and press Mark 1,000 L$ paid. Any remainder stays in the reward balance toward the next payout.

Why not a group?

A private group can still be fun for the two of you, but it is unnecessary for the payment reminder. A direct object IM is simpler and works without group roles, notices, or bots.
