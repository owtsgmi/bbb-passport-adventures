🔔 Payout Alerts

Free browser notifications. No SL script, bot, group, or automatic payment.

The simple version

Passport Adventures can notify you through your normal browser when the recipient's unpaid reward balance reaches another 1,000 L$.

Nothing runs in Second Life. You still make the payment manually. The alert is only a reminder.

1. Enable alerts once on each device

1
Return to Adventures.
2
Under the reward balance, press Enable payout alerts.
3
When your browser asks, choose Allow.

Each browser/device subscribes separately, so you can enable your desktop, laptop, or phone independently.

2. Test it immediately

First press 🖥 Test local popup. Then press 🌐 Test server push.

Important: these alerts appear as normal desktop/system notifications, not as a message inside the Passport Adventures browser tab.

Windows: look for the toast near the lower-right corner or open Notification Center. Linux: look in your desktop notification area; the exact position depends on your desktop environment.

The test notification pretends the recipient has reached the 1,000 L$ threshold, but it changes no adventure history, no reward balance, and no money.

3. Normal use

The server checks the shared reward balance automatically. When the number of available 1,000 L$ payments increases, subscribed devices receive a payout notification even if the Passport Adventures page is closed.

After you manually pay 1,000 L$ in Second Life, press Mark 1,000 L$ paid. Any remainder stays toward the next threshold.

Optional one-click Pay link

Second Life's viewer URI can target an avatar's Pay dialog, but it requires the avatar UUID. Linden Lab provides an official username-to-agent-ID API. If you want this shortcut, use the setup shown in the reward panel: obtain a Linden API key, paste it once, and resolve the saved recipient username.

The Linden API key is sent only for that lookup and is not stored by Passport Adventures. Some external browsers/viewer configurations may still block application-style Second Life links; manual payment by username remains the fallback.
