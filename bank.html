🧪 Passport Bank Test Setup

Dry-run the entire payout path before any real L$ permission exists.

Test first, money later

This TEST object uses the same website → cloud → Second Life → owner approval → result flow we will use for live payouts.

Safe by design: this script never requests debit permission and contains no L$ transfer call. A successful test cannot move Linden dollars.

1. Make the in-world TEST object

1
In Second Life, rez any simple prim that you own personally. Give it a name such as Passport Bank TEST.
2
Open the prim's Contents, create a new script, replace the default script with the test script below, then save it.
3
Touch the object. It will print an 8-digit pairing code only to you in owner chat.
Loading test script…

2. Pair it with the website

1
Return to Adventures and open the Passport Bank section under Mystery L$ Rewards.
2
Enter the 8-digit code and choose Pair test object. The code expires after 10 minutes.
3
The object stores its pairing token in Second Life linkset data so ordinary script resets do not lose the pairing.

3. Run a dry payment

You can test immediately. If no reward is due yet, the website offers a synthetic 1 L$ dry test. If a real unpaid reward exists, the test uses that displayed amount instead.

Press the test button, then approve the matching dialog on the in-world object.

A successful test will show ✓ Test path verified on the website. The real unpaid L$ total stays exactly where it was because test mode never marks a real payment as paid.

After we verify this end-to-end once, the next version can add live mode. Live mode will separately request debit permission and will still require your in-world approval for every transfer.
