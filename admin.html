Notification troubleshooting

Where to look: payout alerts are desktop/system notifications, not messages inside the Passport Adventures browser tab.

Windows: look for the lower-right toast or Notification Center. Linux: look in your desktop notification area. If Chromium/Chrome has blocked the site, use the site-controls icon beside the address bar → Site settings → set Notifications to Allow. For the optional Firestorm Pay shortcut, also allow a pop-up/external-app launch if the browser asks.
