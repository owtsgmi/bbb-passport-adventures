🦄👽 Passport Adventures

How our two-player passport game works

📖 How to Play

This is a lightweight two-person game built around BBB Passport stamp collecting in Second Life. Pick a three-stop adventure, travel together, collect stamps, and finish the whole trio on both passports.

For now, this game is strictly for 2 players. Both players use the same Secret Club Code so the private settings can sync between their devices. Do not share that code with anyone else.

1. Set up both players

1
Open Settings on the Adventures page.
2
Give each tab a name, such as AA and KK.
3
Add each player's BBB StaFi progress-page link.
4
Use the same Secret Club Code on both devices.

The Secret Club Code unlocks encrypted private settings. It is not your BBB password and should not be posted publicly.

2. Pick an adventure

Tap ✨ Pick an Adventure. Each adventure has exactly 3 passport stops.

The current run stays pinned at the top so you can jump back to it easily while you're moving around Second Life.

Use Copy destination or the individual Firestorm copy buttons to get each location.

3. Both passports must finish

One person can get ahead, but the adventure is not complete until both players have all three stamps.

If KK finishes first, the game should show that she is waiting on AA. No reward is unlocked until AA catches up.

4. Unicorn Bucks

Each jointly completed three-stop adventure earns KK 500 Unicorn Bucks, worth 51 L$.

AA is the sponsor/payer. KK is the reward recipient. Switching tabs does not change who owns the Bucks.

5. Cashing out

When enough Bucks are available, KK can redeem them. The site records the payout as due until AA marks it paid.

The site does not transfer Linden dollars itself; it only tracks the promise and payment status.

6. Passport progress

The top stamp counter is meant to show the whole passport total, not only the adventure subset.

Example: 1 / 382 stamps · 381 to go.

Automatic StaFi stamp importing is still being connected. Saving the StaFi link currently saves the private setting; it does not yet mean BBB progress has been imported.

Current two-player limitation: the shared state, Secret Club Code workflow, reward ownership, and payout logic are currently designed for exactly two people. A future public/shared version can support more players, but this version should be treated as a private two-person club.
