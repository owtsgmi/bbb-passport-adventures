🛂 BBB Passport Adventures

Your shared Second Life expedition board — pick a run, rendezvous in-world, collect stamps together.
🚀 Expedition mode: every trip has a code such as A04, and every stop a code such as A04-S3. Paste those into SL IM/local chat: “Meet me at A04-S3 — I’m at the dock.”
The 💬 buttons copy ready-to-paste messages containing the stop code, region, coordinates, and this board URL.
Best way to play: teleport only to the starting area, rez the suggested craft, then travel between stops. Use Me / Partner for separate passport checklists. Each browser stores its own progress, which is useful because your passports are separate. Coordinate in SL with the short trip/stop codes instead of long location names.
